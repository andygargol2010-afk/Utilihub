# Demos de clientes de Vitrina

Cada cliente va en su propia subcarpeta, por ejemplo `demo/barberia-lopez/index.html`,
y se sirve en `https://utilihub.net/vitrina/demo/<cliente>/`.

Toda demo debe llevar en el `<head>`:

```html
<meta name="robots" content="noindex">
```

para que no aparezca en Google mientras es una demo.
